# BhartiyeStudent Study Timer Android

Android Studio project. Open the folder in Android Studio and build an APK.

Features: Maths 2h40m, Reasoning 2h, GK/GS 2h, MP GK 1h; one active timer; foreground service notification; elapsed time based on timestamps so screen lock does not reset the timer; local study progress.

Note: Android manufacturers may apply battery restrictions. For reliable background operation, allow the app to run without battery optimization.
